# Aureon Hub

Aplicativo desktop para Windows com widgets personalizáveis, Notch Carbono e transmissão de tela privada.

O Windows permanece nativo: o aplicativo não substitui nem modifica barra de tarefas, Explorer, atalhos ou papel de parede.

## Estado

Reconstrução v0.1.0 em fase de testes. A transmissão precisa de um servidor de sinalização/TURN e ainda não foi validada em dois PCs com redes diferentes.

Este repositório está sendo preparado para receber a versão reconstruída do código e o workflow de build.
